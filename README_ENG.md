### Ultra is a feature-rich custom firmware for the Nintendo Switch, focused on overclocking and a smoother user experience.

### [UltraNX 3.1|R1+](https://github.com/Ultra-NX/UltraNX/releases/tag/3.1-R1) Supports all HOS up to and including 23.0.1



## Features of Ultra

* Pre-configured Horizon OC (Successor to EOS) with presets.
* The build already includes a mild undervolt, which noticeably reduces power consumption, along with a moderate memory overclock for smoother gameplay.
* The best overclocking tool for the Switch - Ultra-Tuner, lets you fine-tune overclocking directly from the console. It was the first of its kind and remains unique.
* Ultra is kept as lightweight as possible: no unnecessary bloat, only the essentials needed for overclocking and everyday comfort.
* Modular design: only the essentials are included, but you can always add more through Ultra Tuner.
* Custom cooling curve tuning with selectable presets.
* Frequent updates and an active community.
* [Forks](https://github.com/Ultra-NX/Ultra-Resources/tree/main/patches)



## Content of Ultra

1. **[Atmosphere](https://github.com/Atmosphere-NX/Atmosphere)** - Atmosphère, custom firmware for the Nintendo Switch.
1. **[Hekate](https://github.com/CTCaer/hekate)** - Custom Nintendo Switch graphical bootloader, firmware patcher, toolkit and more.
1. **[Ultra Tuner](https://github.com/Ultra-NX/Ultra-Tuner)** - Package for Ultrahand, which allows you to fine-tune the OC parameters for your console. In case of unstable overclocking, or if you want to increase the performance of your console, Ultra Tuner is your indispensable assistant.
1. **[Horizon OC](https://github.com/Horizon-OC/Horizon-OC)** - The Atmosphere loader with overclocking from Soul and Lightos allows you to get the maximum performance out of the Nintendo Switch, bringing it closer to the level of Xbox One. It is regularly updated to support new features of Atmosphere.


1. **Installed Payloads**:
   * [Lockpick RCM](https://github.com/impeeza/Lockpick_RCMDecScots) - Program for dumping console keys.
   * [TegraExplorer](https://github.com/suchmememanyskill/TegraExplorer) - A low-level file manager for system-level operations.


1. **Installed Homebrew**
   * [AiO Switch Updater](https://github.com/HamletDuFromage/aio-switch-updater) - A tool to update Ultra to the latest version and download cheats.
   * [Daybreak](https://github.com/Atmosphere-NX/Atmosphere) - A program for updating HOS.
   * [DBI](https://4pda.to/forum/index.php?showtopic=939714&st=1100#entry86288632) - The best file manager, save manager and program installer on the console.


1. **Installed Modules**
   * [SaltyNX](https://github.com/masagrator/SaltyNX) - Background module allowing to modify files/processes in console, supports plugins.
   * [nx-ovlloader](https://github.com/ppkantorski/nx-ovlloader) - This module lets you toggle installed modules on and off.
   * [sys-patch](https://github.com/impeeza/sys-patch) - Patches the system to run unsigned software instead of sigpatches.
   * [Mission Control](https://github.com/ndeadly/MissionControl) - A module that lets you connect almost any controller to the console via Bluetooth.
   * [sys-con](https://github.com/o0Zz/sys-con) - A module that allows you to connect almost any gamepads to the console via USB.
   * [disable remap dialog](https://github.com/ndeadly/disable_remap_dialog) - A module that hides the remap warning every time you launch a game.
   * [Ultrahand Overlay](https://github.com/ppkantorski/Ultrahand-Overlay) - Special overlay-menu for interacting with the system: overclocking, controlling modes via ReverseNX, enabling cheats, etc. Also allows to use your own packages, for example, Ultra Tuner.
     - [Horizon OC](https://github.com/Horizon-OC/Horizon-OC) - Overlay for controlling sys-clk module.
     - [Status Monitor](https://github.com/ppkantorski/Status-Monitor-Overlay) - Overlay that allows you to monitor console parameters in real time. It can act as an FPS counter. You change preset of Micro-overlay appearance in Tuner.
     - [FPSLocker](https://github.com/masagrator/FPSLocker) - An overlay that unlocks 60 FPS in games.
     - [EdiZon](https://github.com/proferabg/EdiZon-Overlay) - Overlay for using cheats, including graphics.
     - [ReverseNX-RT](https://github.com/ppkantorski/ReverseNX-RT) - An overlay for switching a running game to a handheld\dock mode, which changes the graphics and resolution settings in games.
     - [Sysmodules](https://github.com/ppkantorski/ovl-sysmodules) - Overlay for enabling\disabling installed system modules.


1. **Available for download via Updater**
   * Homebrews:
      * [DBI](https://4pda.to/forum/index.php?showtopic=939714&st=1100#entry86288632) - Here you can download a DBI or update an existing one.
      * [AIO](https://github.com/HamletDuFromage/aio-switch-updater) - Downloads the configured AIO for UltraNX.
      * [Linkalho](https://gbatemp.net/download/linkalho.38822/) - Account linking program. Some games won't work without the link.
      * [PPSSPP](https://github.com/NaGaa95/ppsspp-nx) - PSP emulator.
      * [DuckStation](https://github.com/shooterspps/duckstation) - PS1 emulator.
      * [Moonlight](https://github.com/XITRIX/Moonlight-Switch) - Moonlight client, allows to stream games from PC.
      * [ThemezerNX](https://github.com/suchmememanyskill/themezer-nx) + [NXThemes Installer](https://github.com/exelix11/SwitchThemeInjector) + [Theme Patches](https://github.com/exelix11/theme-patches) - Search for and install themes on the Switch.
      * [Battery Desync Fix](https://github.com/CTCaer/battery_desync_fix_nx) - A utility to reset the battery controller. Do not use unnecessarily!
      * [MemToolkitNX](https://discord.com/channels/854839758815363072/1173171845139288114/1324099100202766408) - Benchmark and Memory Tester. The result is highly dependent on CPU overclocking.
      * [MemToolkitNX OLD](https://discord.com/channels/854839758815363072/1173171845139288114/1276196700750479480) - Benchmark and Memory Tester. The result is highly dependent on CPU overclocking. The old version, which many people like better than the new one.
      * [MicroMemBench](https://github.com/rashevskyv/4IFIR) - Benchmark. The result depends heavily on CPU overclocking. This 4IFIR version tests CPU Copy performance in real time, allowing you to quickly evaluate the effect of timing changes.

   * Overlays:
      * [Status Monitor](https://github.com/ppkantorski/Status-Monitor-Overlay) - Status Monitor fork from kantorski.
      * [sys-dock](https://github.com/masagrator/sys-dock) - A module that lets you change the refresh rate of the connected display through the dock.
      * [Tetris](https://github.com/ppkantorski/Tetris-Overlay/) - "That" game in the form of an overlay. Works only on the latest versions of Ultrahand.
      * [MasterVolume](https://github.com/averne/MasterVolume) - Global volume control, allows you to raise the volume above the maximum. Use with care!
      * [NX-FanControl](https://github.com/Lightos1/NX-FanControl) - Module for manually adjusting the speed of the cooler. The changes are applied immediately, the module works from SOC temperature and not Skin temperature like Atmosphere.
      * [BT Audio](https://github.com/masagrator/BT_Audio-ovl) - An overlay that lets you quickly connect or disconnect a Bluetooth headset.
      * [Fizeau](https://github.com/averne/Fizeau) + [Fizeau Overlay Fork](https://github.com/ppkantorski/Fizeau) - Module for changing the screen color profile.
      * [sys-tune](https://github.com/ppkantorski/sys-tune) - Overlay music player, works in background.

   * Other:
      * [FPSLocker Patches](https://github.com/masagrator/FPSLocker-Warehouse) - The FPSLocker patch pack lets you update all patches at once instead of downloading them one by one through the FPSLocker overlay. UltraNX always has the latest patches by default, so it's enough to update the CFW in a timely manner.
      * [DVR Patches](https://github.com/exelix11/dvr-patches) - SysDVR patches, work without the system module, activating background recording in games where it is initially prohibited.
      * [Mod Alchemist](https://github.com/ppkantorski/Alchemist) - A package for downloading, installing, and managing mods for games.
      * [sys-ftpd](https://github.com/ELY3M/sys-ftpd) - FTP server running in background.
